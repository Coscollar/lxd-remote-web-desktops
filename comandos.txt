Instalar LXD: 
	sudo snap install LXD
	
Ver que el user de la maquina es parte del grupo de LXD: 
	getent group lxd | grep "$USER"
	
Si el comando no saca nada ejecutar:
	sudo usermod -aG lxd "$USER"
	newgrp lxd

Pools ZFS:
Crea el pool ZFS para contenedores stateless
	sudo lxc storage create stateless-pool zfs size=20GB
Crea el pool ZFS para VMs persistentes
	sudo lxc storage create persistent-pool zfs size=40GB

Imágenes (puede disponerse de otras):
Añadir el remote oficial de ubuntu para mas imagenes
	lxc remote add ubuntu-releases https://cloud-images.ubuntu.com/releases --protocol simplestreams
Obtener lista de imagenes
	lxc image list ubuntu-releases: | grep 22.04 | grep x86_64
Nos quedamos con la ultima de container y virtual-machine
	lxc image copy ubuntu-releases:cf181d732f32 local: --alias ubuntu-22.04-vm
	lxc image copy ubuntu-releases:a6d2f7222476 local: --alias ubuntu-22.04-container

Inicializar LXD a partir de un archivo de configuración
	lxd init --preseed < lxd-preseed.yaml

Validaciones tras la configuración:
lxc storage list
lxc network list
lxc profile list
lxc project list
lxc image list local

FASE 6 — Apps stateless (contenedores LXD, perfil stateless):

Construir imagen de app (builder, espejo de build-lab-vm-base-mate.sh):
	sudo bash build-apps/build-app-jupyter.sh
	sudo bash build-apps/build-app-jupyter.sh --force   # reconstruir

Listar imágenes de apps:
	lxc image list local --project labs | grep app-

Lanzar app shared (manual, normalmente vía provision-api job queue):
	lxc launch local:app-jupyter app-jupyter -p stateless --project labs -c boot.autostart=true

Lanzar app per-alumno:
	lxc launch local:app-jupyter app-jupyter-alumno1 -p stateless --project labs

Healthcheck HTTP de app (HTTP real, no TCP):
	IP=$(lxc list app-jupyter -c4 --format csv --project labs | cut -d, -f1)
	curl -sf http://${IP}:8888/

Detener/eliminar app (idempotente):
	lxc stop app-jupyter --project labs --timeout=30 || lxc stop app-jupyter --project labs --force
	lxc delete -f app-jupyter --project labs

Ampliar stateless-pool (no destructivo, NO --force-preseed que destruiría persistent-pool):
	lxc storage set stateless-pool size=80GB

Ampliar subred lab-stateless a /23 (no destructivo):
	lxc network set lab-stateless ipv4.address=10.50.10.1/23 --project labs
	lxc network set lab-stateless ipv4.address=10.50.10.1/23 --project default

Aislamiento iptables apps:
	sudo bash nginx/iptables-apps.sh

Validaciones FASE 6:
	lxc image list local --project labs | grep app-
	lxc list ^app- --project labs
	sudo iptables -L FORWARD -n | grep lab-stateless
	sudo ss -tlnp | grep -E ':(3389|5900|3000|8888)'   # debe estar vacío
